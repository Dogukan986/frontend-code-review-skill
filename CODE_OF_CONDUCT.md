# Code of Conduct

We want this project to be a welcoming, respectful place for everyone.

- Be kind and constructive. Critique code and ideas, not people.
- No harassment, discrimination, personal attacks or unwelcome sexual attention.
- Assume good faith, and ask when something is unclear.
- Do not publish other people's private information.

Maintainers may remove comments, commits or contributions that violate these rules and may ban repeat offenders. Report problems by opening a private security advisory or contacting the maintainer through the email on their GitHub profile.

This text is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
